# Learned Facts

this file holds things brodar has picked up over time — user preferences, running
context, small notes. it's mutable: the bot appends to it via `save_memory_fact` and
it's synced to the database so it survives restarts.

the core personality does NOT live here — that's in `PERSONA.md`, which is fixed and
cannot be edited by the model. this file only adds facts on top of that persona.
